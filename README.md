## 📖 فلسفة التطبيق (The Core Philosophy)
تطبيق **"مُحاسبة"** مبني على منهج التزكية الإسلامي الأصيل لتنقية النفس وضبط اليوم في ثلاث محطات رئيسية:

1. **المشارطة (صباحاً بعد الفجر):**  
   مشارطة النفس على الطاعة بتحديد "نية اليوم" الإيمانية، وتعيين زلة أو خلق ذميم يعزم المسلم على حراسة نفسه منه طوال النهار.
2. **المراقبة (خلال ساعات النهار):**  
   مراقبة الجوارح، أداء الصلوات الخمس في أوقاتها مع السنن والرواتب وأذكار الصلاة، وإتمام ورد القرآن وتدبر آية، وذكر الله بالسبحة الرقمية.
3. **المحاسبة وتخلية القلب (مساءً قبل النوم):**  
   خلوة 3 دقائق لمساءلة النفس: حفظ اللسان، غض البصر، أداء الأمانات، وسلامة الصدر بالعفو والصفح عن كل من أساء للنوم بقلب طاهر سليم، وختم اليوم بالاستغفار.

## ✨ المميزات الرئيسية (Key Features)

### 1. المشارطة الصباحية (عزم اليوم)
- تعيين نية اليوم الصالحة مع مقترحات جاهزة (إخلاص العمل، بر الوالدين، كظم الغيظ، إتقان الوظيفة).
- تحديد الزلة أو العادة المنهي عنها المراد اجتنابها (الغيبة، إدمان الشاشات، الغضب، فضول النظر).
- زر إبرام العزم واحتساب رصيد الصباح.

### 2. متابعة الصلوات والأوراد
- مصفوفة تفاعلية للصلوات الخمس (الفجر، الظهر، العصر، المغرب، العشاء).
- شارات تدقيق دقيقة لكل صلاة: **(في وقتها • في جماعة • السنن الرواتب • أذكار الصلاة)**.
- خيارات سريعة للسنن والنوافل: **صلاة الضحى** و**قيام الليل والوتر**.
- جلب مواقيت الصلاة الحية آلياً حسب المدينة عبر Aladhan API مع دعم العمل دون إنترنت.

### 3. ورد القرآن والتدبر العملي
- عداد مرن لعدد الصفحات المقروءة اليوم واختيار رقم الجزء.
- بطاقة تدبر تفاعلية: توثيق الآية المستوقفة، وتدوين الأثر الإيماني والتطبيق السلوكي في اليوم.
- أرشيف وسجل للتدبرات السابقة للرجوع إليها ومراجعتها.

### 4. السبحة الرقمية وحصن الأذكار
- سبحة إلكترونية بنقر واقعي وصوت ناعم مُصنَّع عبر Web Audio API مع اهتزاز لمسي (Haptic Feedback).
- تنقل سهل بين الأذكار النبوية المأثورة وتحديد أهداف العد (33 / 100 / عد حر) مع تأثيرات احتفالية عند الإتمام.
- قوائم تدقيق لأذكار الصباح، أذكار المساء، وأذكار ما قبل النوم.

### 5. المحاسبة المسائية وتخلية القلب
- 4 بطاقات تدقيق بمفاتيح تبديل سريعة:
  1. **حفظ اللسان:** النجاة من الغيبة والنميمة وفضول القول.
  2. **غض البصر:** صيانة العين والسمع والجوارح في الواقع والشاشات.
  3. **أداء الأمانة:** النزاهة والإتقان في المسؤوليات والعمل.
  4. **سلامة الصدر:** العفو والصفح لوجه الله قبل النوم.
- عداد الاستغفار المسائي لتجديد التوبة والمبيت على طهارة باطنة.

### 6. مؤشر الصحة الإيمانية الذكي (Spiritual Health Dashboard)
- حلقة تقدم دائرية بصرية تحسب نسبة الالتزام اليومي التراكمية (0 - 100%).
- متابعة استمرارية صحية دون ضغط نفسي أو تراجع محبط (Mindful Streak).

### 7. نظام التنبيهات الإيمانية الذكي
- تذكيرات هادئة موقوتة بمواقيت الصلاة وشروق الشمس والنوم:
  - *الفجر + 15 دقيقة:* المشارطة وتحديد نية اليوم.
  - *الضحى:* ركعتا الضحى وأذكار الصباح.
  - *العصر:* أذكار المساء وورد التدبر.
  - *قبل النوم:* المحاسبة وتخلية القلب والاستغفار.
- إمكانية تجربة نغمة التنبيه الهادئة وطلب أذونات إشعارات المتصفح مباشرة.

## 🎨 الهوية البصرية والتصميم (UI/UX Style Guide)
- **فلسفة التصميم:** بساطة عصرية مستوحاة من Pinterest و Notion بأجواء روحانية هادئة.
- **لوحة الألوان:**
  - `Sage Green` (#4A6B5D): لون الصفاء والسكينة الأساسي.
  - `Warm Cream` (#FAF8F5): خلفية ورقية مريحة للعين.
  - `Soft Slate` (#2D3748): نصوص وأيقونات رصينة.
  - `Subtle Gold` (#C5A880): لمسات ذهبية هادئة للشارات والمواقيت.
- **الخطوط والطباعة:** خط `Tajawal` للواجهات الحديثة وخط `Amiri` للآيات والأذكار.
- **التوافق:** دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL)، مع دعم كامل للوضع الليلي المريح (Dark Mode).

## 🗄️ بنية قاعدة البيانات (Supabase / PostgreSQL)
الملف المرفق [`schema.sql`](./schema.sql) يتضمن المخطط الكامل مع تفعيل سياسات الأمان على مستوى الصفوف (Row Level Security):
- `profiles`: بيانات المستخدمين، الإحداثيات، المنطقة الزمنية، ومذهب الحساب الفلكي.
- `daily_logs`: سجل اليوم الكامل (المشارطة، مؤشرات المحاسبة، ورصيد اليوم).
- `prayer_logs`: تفاصيل الصلوات الخمس والسنن وأذكار ما بعد الصلاة.
- `quran_reflections`: صفحات التلاوة، مرجع الآية، ونصوص التدبر العملي.
- `adhkar_logs`: أوراد الذكر وجلسات التسبيح.
- `notification_settings`: ضبط فوارق التنبيهات وإعدادات الإشعارات.

## 🚀 التشغيل والتطوير المحلي (Local Development)

التطبيق مصمم كصفحة ويب تفاعلية حديثة ومستقلة تماماً، يمكن تشغيلها مباشرة عبر أي خادم محلي:

```bash
# استنساخ المستودع
git clone https://github.com/mohamedjs/muhasabah.git
cd muhasabah

# تشغيل الخادم المحلي (أو عبر VS Code Live Server)
npx serve .
# أو
python3 -m http.server 8000
```

افتح المتصفح على: `http://localhost:8000`
